# Quiz Web Application

## Description

The **Quiz Web Application** is a backend-based web application developed using **Java, Spring Boot, RESTful APIs, Spring Data JPA, Hibernate, and MySQL**. The application allows users to manage and interact with quiz questions through REST APIs.

The project provides functionality to **create, retrieve, update, and delete quiz questions**, along with multiple-choice options and correct answers. It uses **Spring Data JPA and Hibernate** for database operations and **MySQL** for persistent data storage.

The application follows a **layered architecture** using Controller, Service, and Repository layers, making the project easy to maintain, test, and extend.

## Key Features

- Create quiz questions with multiple options
- Store correct answers
- Retrieve quiz questions
- Update existing questions
- Delete questions
- RESTful API implementation
- MySQL database integration
- Spring Data JPA and Hibernate
- CRUD operations
- Layered architecture
- API testing using Postman
